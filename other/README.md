# DSA in Java

A collection of Java programs implementing various Data Structures and Algorithms.

## Topics Covered

This project contains solutions for the following DSA topics:

- Math

## Project Structure

The project is organized into folders based on DSA topics. Each folder contains Java programs related to that topic.

```
DSA-Java/
├── Math/
│   └── ArmstrongNumber.java
└── README.md
```

## How to Compile and Run

To compile and run a specific program, follow these steps:

1.  **Navigate to the topic folder:**

    ```bash
    cd <TopicFolder>
    ```

    For example:

    ```bash
    cd Math
    ```

2.  **Compile the Java file:**

    ```bash
    javac <FileName>.java
    ```

    For example:

    ```bash
    javac ArmstrongNumber.java
    ```

3.  **Run the compiled class:**

    ```bash
    java <ClassName>
    ```

    For example:

    ```bash
    java checkAmstrongOrNot
    ```

    (Note: The class name is `checkAmstrongOrNot` inside `ArmstrongNumber.java`)

# ☕ Java Programs Collection

A collection of basic to intermediate Java programs covering core programming concepts, data structures, and problem-solving techniques. This repository is intended for learning, practice, and academic purposes.

## 📌 Features

- Fundamental Java programs
- Object-Oriented Programming (OOP) concepts
- Control statements and loops
- Functions and recursion
- Arrays and basic data structures
- Practice problems and examples

## 🛠️ Technologies Used

- Java (JDK 8 or above)
- Command Line / Terminal
- Any Java IDE (IntelliJ IDEA, Eclipse, VS Code)
